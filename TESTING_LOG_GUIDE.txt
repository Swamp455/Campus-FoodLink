CAMPUS FOODLINK+ UNIT 8 LOGGING GUIDE

1. Use a local web server or deploy all files together to GitHub Pages.
2. Open index.html. The Unit 8 Test Logger appears at the bottom-right of every page.
3. Select the test case ID before performing each test.
4. Run the test. The logger records button clicks, browser validation, displayed errors, logins, localStorage saves, orders and some staff actions.
5. Inspect the result and select Mark Pass or Mark Fail. This is a manual judgment; the logger does NOT automatically assert test success.
6. Export CSV for your Unit 8 tracking table or JSON for technical evidence. Save screenshots as well.
7. Export before Reset Demo Data or clearing site storage; logs are kept in browser localStorage and are browser/device specific.
8. Never enter real student data. Demo passwords are never logged. Do not interpret browser-based login as production security.
9. Data layer evidence is for browser localStorage only, NOT live MySQL.
10. To remove logging, remove the test-logger.js script tag from the five HTML pages.

The existing Export JSON on the staff page is the prototype DATA export; the logger exports separate TEST EVENT evidence.
