Campus FoodLink+ Wireframe-Aligned Build
This prototype contains five HTML pages: index.html, account.html, menu.html, confirmation.html, and orders.html. The app.js file provides application behavior, student and staff navigation, vendor selection, order processing, validation, and localStorage persistence. The apps.json file contains the demo student and staff accounts, multiple vendors and their menu items, meal-plan balance, and available order statuses. Students can select a vendor from a dropdown menu, add menu items to their cart, choose a pickup time, place an order, and view the current order status. Staff can view the current order and update its status and notes.
